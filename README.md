**The method, written down**

[marketing-skills](https://github.com/anshudaswani/marketing-skills) is how I work, codified so an agent can run it. Four pillars: Deep Understanding, Market Translation, Infrastructure, Narrative Coherence. Each skill ships with a sample output on a real company built from public information, so you can judge the thinking, not just the prompt. One check runs on everything: could a competitor have published this? If yes, send it back.

The same method, pointed at my own job search, runs an interview coach inside a private operating system I built in Lovable: paste a call transcript and it logs what tested me and what it says about how I interview.
